## 1. 项目概述

### 1.1 项目定位

**AI Insight Hub** 是一个为 AI 客服/对话系统提供数据清洗、质量评估、知识构建和洞察分析的智能数据中台。

### 1.2 核心价值

```
不是审核"人工客服"，而是管理和优化"AI 客服"
通过数据中台能力，让 AI 客服持续进化
```

### 1.3 技术栈

```
前端: React 18 + Vite 5 + TailwindCSS 3
后端: Python 3.11 + FastAPI + SQLAlchemy 2.0
AI:   LangChain + LangGraph + Claude 5.5
数据: PostgreSQL 14+ (pgvector) + Redis 7+
部署: Docker + Docker Compose
```

### 1.4 MVP 功能范围

**P0 核心功能**（必须有）：
- ✅ 数据源管理（CRUD）
- ✅ 数据清洗 Agent
- ✅ 质量评估 Agent
- ✅ 知识提取 Agent
- ✅ 基础报告生成

**P1 重要功能**（应该有）：
- ⏸️ 洞察分析 Agent
- ⏸️ 多格式报告导出
- ⏸️ 实时监控 Dashboard

**P2 增强功能**（可以没有）：
- ⏸️ 多用户支持
- ⏸️ API 密钥管理
- ⏸️ Webhook 通知

import asyncpg
from sentence_transformers import SentenceTransformer

async def test_pgvector_basic():
    """测试 pgvector 基础功能"""
    # 连接数据库
    conn = await asyncpg.connect(
        "postgresql://aiinsight:dev_password@localhost/aiinsight"
    )
    
    # 创建测试表
    await conn.execute("""
        CREATE EXTENSION IF NOT EXISTS vector;
        CREATE TABLE IF NOT EXISTS test_embeddings (
            id SERIAL PRIMARY KEY,
            content TEXT,
            embedding VECTOR(384)
        );
    """)
    
    # 生成嵌入
    model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
    texts = [
        "iPhone 14 的价格是 5999 元",
        "退货需要 7 天内",
        "支持分期付款"
    ]
    
    # 插入数据
    for text in texts:
        embedding = model.encode(text).tolist()
        await conn.execute(
            "INSERT INTO test_embeddings (content, embedding) VALUES ($1, $2)",
            text, embedding
        )
    
    # 相似度搜索
    query = "iPhone 14 多少钱"
    query_embedding = model.encode(query).tolist()
    
    results = await conn.fetch("""
        SELECT content, 1 - (embedding <=> $1) AS similarity
        FROM test_embeddings
        ORDER BY embedding <=> $1
        LIMIT 3
    """, query_embedding)
    
    assert len(results) > 0
    assert results[0]['similarity'] > 0.5
    print(f"✅ 最相似: {results[0]['content']} (相似度: {results[0]['similarity']:.2%})")

from langgraph.graph import StateGraph, END
from typing import TypedDict

class State(TypedDict):
    input: str
    cleaned: str
    evaluated: dict
    status: str

def cleaning_node(state: State) -> State:
    """模拟清洗"""
    state["cleaned"] = state["input"].strip().upper()

# app/agents/extraction_agent.py
from sentence_transformers import SentenceTransformer

class KnowledgeExtractionAgent(BaseAgent):
    """知识提取 Agent"""
    
    def __init__(self):
        super().__init__()
        self.embedding_model = SentenceTransformer(
            'paraphrase-multilingual-MiniLM-L12-v2'
        )
    
    async def extract(self, dialogues: list) -> dict:
        """提取知识"""
        # 1. 提取问题
        questions = await self._extract_questions(dialogues)
        
        # 2. 聚类
        clusters = self._cluster_similar(questions)
        
        # 3. 提取标准答案
        faqs = []
        for cluster in clusters:
            answer = await self._extract_answer(cluster)
            embedding = self.embedding_model.encode(cluster[0]['question'])
            
            faqs.append({
                "question": cluster[0]['question'],
                "answer": answer,
                "frequency": len(cluster),
                "embedding": embedding.tolist()
            })
        
        return {"faqs": faqs}
