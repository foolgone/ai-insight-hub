## 6. 已知限制登记（上线前告知）

1. `LLM_PRICE_*` 默认 0：成本金额为 0，需业务方提供单价；
2. `DEGRADED_LLM_MODEL` 留空：降级只告警不切模型（D-09 决定）；
3. 报告仅 markdown/excel；pdf/html → 422（D-11 降级方案）；
4. Prompt 金标准语义基线待首次真实跑批人工确认；
5. MinIO 不可用时自动本地存储回退（VM 当前路径）；
6. 100 并发 P95 基线未执行（需独立压测环境；脚本 `tests/load/`）；
7. Docker 镜像未在本机构建（daemon 未运行），compose 配置已校验；
8. `api_keys` / `webhooks`（B-706）不做，明确在 MVP 范围之外。

- `llm_calls` 成本合计 vs 预算；`X-Cost-Status` 是否进入 warning；
- Celery 队列长度/失败率；任务 pending 堆积；
- API P95、5xx 率、限流/降级触发次数；
