## 1. 问题描述

### 当前问题

原有成本管理文档提到了预警和限流，但没有明确：

❌ 成本达到限额后的具体行为  
❌ 是完全停止服务还是降级？  
❌ 降级的具体策略是什么？  
❌ 如何通知用户？  

### 影响

- 可能导致服务完全中断，影响用户体验
- 用户不知道为什么服务突然不可用
- 没有缓冲机制，要么正常要么停止

## 2. 降级策略设计

### 2.1 四级降级策略

```
┌────────────────────────────────────────────────┐
│  成本使用情况      │  阈值  │  动作            │
├────────────────────────────────────────────────┤
│  正常使用          │  < 80% │  ✅ 正常服务     │
│  接近限额          │  80%   │  ⚠️  预警通知    │
│  达到限额          │  90%   │  🔶 开始限流     │
│  超出限额          │  100%  │  🔻 降级服务     │
│  严重超限          │  120%  │  🛑 停止服务     │
└────────────────────────────────────────────────┘
```

---

### 2.2 详细降级规则

#### 阶段 1: 正常服务 (< 80%)

```python
状态: "normal"
行为:
  - ✅ 使用默认模型（Claude Sonnet 5.5）
  - ✅ 无限流
  - ✅ 全部功能可用
  - ✅ 无降级
```

---

#### 阶段 2: 预警通知 (80-90%)

```python
状态: "warning"
行为:
  - ⚠️  发送预警邮件/站内通知
  - ✅ 服务正常运行
  - 📊 增加成本监控频率（每 10 分钟检查）
  
通知内容:
  "您的今日成本已达到 {usage_pct}%（${current_cost}/${daily_limit}）
   请注意控制使用，避免服务受限"
```

---

#### 阶段 3: 开始限流 (90-100%)

```python
状态: "throttled"
行为:
  - 🔶 降低 QPS 限制（从 60 → 30 请求/分钟）
  - ✅ 继续使用默认模型
  - ✅ 核心功能可用
  - ⏸️  非核心功能（报告生成）排队处理
  
响应头添加:
  X-RateLimit-Remaining: 30
  X-RateLimit-Reset: 1698076800
  X-Cost-Usage: "92%"
  X-Cost-Status: "throttled"
```

---

#### 阶段 4: 降级服务 (100-120%)

```python
状态: "degraded"
行为:
  - 🔻 切换到廉价模型（Claude Haiku 5.5）
  - 🔻 QPS 限制进一步降低（30 → 10 请求/分钟）
  - ⏸️  暂停后台任务（批量处理、定时报告）
  - ✅ 核心功能保持可用（数据清洗、评估）
  
用户提示:
  "您的成本配额已用尽，当前使用经济模式
   功能可能受限，建议升级套餐或明日再试"
```

**模型降级对比**：

| 维度 | Sonnet 5.5 | Haiku 5.5 | 影响 |
|------|-----------|----------|------|
| 成本 | $0.018/1K | $0.0048/1K | **省 73%** |
| 速度 | 1.0x | 1.5x | 更快 |
| 准确率 | 95% | 85% | 下降 10% |

```python
状态: "stopped"
行为:

# app/core/degradation.py
from enum import Enum
from typing import Dict, Any

class DegradationLevel(Enum):
    """降级级别"""
    NORMAL = "normal"
    WARNING = "warning"
    THROTTLED = "throttled"
    DEGRADED = "degraded"
    STOPPED = "stopped"

class DegradationConfig:
    """降级配置"""
    
    THRESHOLDS = {
        DegradationLevel.WARNING: 0.80,    # 80%
        DegradationLevel.THROTTLED: 0.90,  # 90%
        DegradationLevel.DEGRADED: 1.00,   # 100%
        DegradationLevel.STOPPED: 1.20     # 120%
    }
    
    ACTIONS = {
        DegradationLevel.NORMAL: {
            "model": "claude-sonnet-5-5",
            "qps_limit": 60,
            "features": ["all"],
            "background_tasks": True
        },
        DegradationLevel.WARNING: {
            "model": "claude-sonnet-5-5",
            "qps_limit": 60,
            "features": ["all"],
            "background_tasks": True,
            "notify": True
        },
        DegradationLevel.THROTTLED: {
            "model": "claude-sonnet-5-5",
            "qps_limit": 30,
            "features": ["all"],
            "background_tasks": True
        },
        DegradationLevel.DEGRADED: {
            "model": "claude-haiku-5-5",  # 降级到 Haiku
            "qps_limit": 10,
            "features": ["clean", "evaluate"],  # 只保留核心功能
            "background_tasks": False  # 暂停后台任务
        },
        DegradationLevel.STOPPED: {
            "model": None,
            "qps_limit": 0,
            "features": [],  # 无 AI 功能
            "background_tasks": False
        }
    }
```

### 3.2 降级管理器

```python
# app/core/degradation_manager.py
from datetime import datetime, timedelta
import logging

logger = logging.getLogger(__name__)

class DegradationManager:
    """降级管理器"""
    
    def __init__(self, cost_tracker, redis_client):
        self.cost_tracker = cost_tracker
        self.redis = redis_client
    
    async def get_degradation_level(self, user_id: str) -> DegradationLevel:
        """获取当前降级级别"""
        
        # 1. 获取用户配额和使用情况
        user = await self.get_user(user_id)
        daily_limit = user.quota.get("daily_cost_limit", 100.0)
        
        # 2. 获取今日成本
        today_cost = await self.cost_tracker.get_daily_cost(user_id)
        
        # 3. 计算使用比例
        usage_ratio = today_cost / daily_limit if daily_limit > 0 else 0
        
        # 4. 确定降级级别
        if usage_ratio >= DegradationConfig.THRESHOLDS[DegradationLevel.STOPPED]:
            return DegradationLevel.STOPPED
        elif usage_ratio >= DegradationConfig.THRESHOLDS[DegradationLevel.DEGRADED]:
            return DegradationLevel.DEGRADED
        elif usage_ratio >= DegradationConfig.THRESHOLDS[DegradationLevel.THROTTLED]:
            return DegradationLevel.THROTTLED
        elif usage_ratio >= DegradationConfig.THRESHOLDS[DegradationLevel.WARNING]:
            return DegradationLevel.WARNING
        else:
            return DegradationLevel.NORMAL
    
    async def get_degradation_config(self, user_id: str) -> Dict[str, Any]:
        """获取降级配置"""
        
        level = await self.get_degradation_level(user_id)
        config = DegradationConfig.ACTIONS[level].copy()
        
        # 添加额外信息
        today_cost = await self.cost_tracker.get_daily_cost(user_id)
        user = await self.get_user(user_id)
        daily_limit = user.quota.get("daily_cost_limit", 100.0)
        
        config.update({
            "level": level.value,
            "usage_ratio": today_cost / daily_limit,
            "current_cost": today_cost,
            "daily_limit": daily_limit,
            "reset_at": self._get_reset_time()
        })
        
        return config
    
    def _get_reset_time(self) -> datetime:
        """获取重置时间（明天凌晨）"""
        tomorrow = datetime.now() + timedelta(days=1)
        return tomorrow.replace(hour=0, minute=0, second=0, microsecond=0)
    
    async def should_degrade_to_haiku(self, user_id: str) -> bool:
        """是否应该降级到 Haiku"""
        level = await self.get_degradation_level(user_id)
        return level in [DegradationLevel.DEGRADED]
    
    async def is_service_stopped(self, user_id: str) -> bool:
        """服务是否已停止"""
        level = await self.get_degradation_level(user_id)
        return level == DegradationLevel.STOPPED
```

### 3.3 中间件集成

```python
# app/middleware/degradation_middleware.py
from fastapi import Request, HTTPException
from starlette.middleware.base import BaseHTTPMiddleware

class DegradationMiddleware(BaseHTTPMiddleware):
    """降级中间件"""
    
    async def dispatch(self, request: Request, call_next):
        # 1. 获取用户
        user_id = getattr(request.state, "user_id", None)
        
        if not user_id:
            return await call_next(request)
        
        # 2. 检查降级状态
        degradation_manager = request.app.state.degradation_manager
        config = await degradation_manager.get_degradation_config(user_id)
        
        # 3. 如果服务已停止
        if config["level"] == "stopped":
            raise HTTPException(
                status_code=429,
                detail={
                    "error": "DAILY_COST_LIMIT_EXCEEDED",
                    "message": "您的每日成本限额已超限，服务已暂停",
                    "current_cost": config["current_cost"],
                    "daily_limit": config["daily_limit"],
                    "reset_at": config["reset_at"].isoformat(),
                    "suggestion": "请升级套餐或等待明日重置"
                }
            )
        
        # 4. 添加降级信息到请求状态
        request.state.degradation_config = config
        
        # 5. 执行请求
        response = await call_next(request)
        
        # 6. 添加降级信息到响应头
        response.headers["X-Cost-Usage"] = f"{config['usage_ratio']:.1%}"
        response.headers["X-Cost-Status"] = config["level"]
        response.headers["X-Cost-Reset"] = config["reset_at"].isoformat()
        
        if config["level"] in ["throttled", "degraded"]:
            response.headers["X-RateLimit-Limit"] = str(config["qps_limit"])
        
        return response

# 在 main.py 中注册
app.add_middleware(DegradationMiddleware)
```

### 3.4 Agent 集成降级

```python
# app/agents/base.py
class BaseAgent:
    """Agent 基类（集成降级）"""
    
    async def invoke(self, input_data: dict, user_id: str = None) -> dict:
        """执行 Agent（自动降级）"""
        
        if not user_id:
            # 没有用户ID，使用默认配置
            return await self._execute(input_data, model="claude-sonnet-5-5")
        
        # 1. 获取降级配置
        degradation_manager = DegradationManager(...)
        config = await degradation_manager.get_degradation_config(user_id)
        
        # 2. 检查服务是否停止
        if config["level"] == "stopped":
            raise ServiceUnavailableError("成本限额已超限，服务暂停")
        
        # 3. 选择模型
        model = config["model"]
        
        # 4. 执行
        if config["level"] == "degraded":
            logger.warning(
                f"User {user_id} using degraded service (Haiku model)"
            )
        
        result = await self._execute(input_data, model=model)
        
        # 5. 在结果中标注降级信息
        result["_degradation"] = {
            "level": config["level"],
            "model_used": model,
            "is_degraded": config["level"] in ["degraded", "throttled"]
        }
        
        return result
```

from celery import Celery

celery_app = Celery("ai_insight_hub")

@celery_app.task
async def monitor_user_costs():
    """监控所有用户的成本（每 10 分钟运行）"""
    
    degradation_manager = DegradationManager(...)
    
    # 获取所有活跃用户
    active_users = await get_active_users()

        # 检查是否需要发送通知

            # 只在第一次达到 80% 时通知
            if not await has_sent_warning(user.id):
                await send_warning_notification(user)
                await mark_warning_sent(user.id)
        
        elif level == DegradationLevel.DEGRADED:
            # 达到 100% 时通知

                await send_degraded_notification(user)
                await mark_degraded_sent(user.id)

            # 超过 120% 时通知
            if not await has_sent_stopped_notification(user.id):
                await send_stopped_notification(user)
                await mark_stopped_sent(user.id)

            AI Insight Hub 团队
            """

            title="成本预警",
            content=f"今日成本已达 {config['usage_ratio']:.1%}，请注意控制",

import { useEffect, useState } from 'react';
