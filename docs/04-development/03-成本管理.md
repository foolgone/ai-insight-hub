## 0. 单价参数（全项目唯一口径）

> **原则**：文档与代码都**不写死模型单价**。单价由配置注入，所有成本数字一律由公式推导。

| 参数 | 含义 | 取值 |
|---|---|---|
| `P_IN` | 输入单价（USD / 百万 token） | ⚠️ 待按 DeepSeek V4.1 Flash 官方单价填入 |
| `P_OUT` | 输出单价（USD / 百万 token） | ⚠️ 待按 DeepSeek V4.1 Flash 官方单价填入 |

**计算公式**：

```
单次调用成本 = (输入 token × P_IN + 输出 token × P_OUT) / 1_000_000
月成本       = (月输入 token × P_IN + 月输出 token × P_OUT) / 1_000_000
```

**模拟示例（占位，非真实单价）**：当 `P_IN = $a`、`P_OUT = $b` 时，
月输入 50,000,000 token、月输出 15,000,000 token 的月成本为

```
(50,000,000 × a + 15,000,000 × b) / 1_000_000 = 50a + 15b  （USD）
```

⚠️ `a` / `b` 只是占位符，**禁止当作真实预算引用**；真实取值以官方定价页为准。

**两种成本口径（全项目统一，引用时必须标注）**：

| 口径 | 含义 | 用途 |
|---|---|---|
| **LLM-only 单条成本** | 只含 token 费用，不含数据库/存储/服务器 | 模型横向比较、「模型贵不贵」 |
| **含基础设施的单条成本** | （LLM + 数据库 + 存储 + 服务器 + Redis）/ 月处理条数 | 对外报价、预算评审 |

> 历史文档中 `$0.00849`（LLM-only）与 `$0.0127`（含基础设施）并存且未标注口径，已按本表统一。

## 1. 成本概述

### 1.1 AI 应用的成本结构

```
总成本 = LLM Token 成本 + 基础设施成本 + 人力成本

经验占比（随单价与规模变化，仅供结构参考）：
- LLM Token 成本：主要成本项
- 基础设施成本：服务器、数据库、存储
- 人力成本：开发、运维
```

**本文档重点**：LLM Token 成本优化

---

### 1.2 Token 用量结构（与模型无关）

单价绝对值随模型变化，但**每次调用的 token 结构是稳定的**，这部分假设可长期复用。

**每 1000 条对话的 token 用量（⚠️ 待真实样本校准，确认方式：清洗 1000 条真实对话后统计）**：

| 场景 | 输入 token | 输出 token | 说明 |
|------|-----------|-----------|------|
| 数据清洗 | 450K | 100K | 每条 450 in / 100 out |
| 质量评估 | 650K | 200K | 含知识库上下文 |
| 知识提取（批量 100 条/批） | 80K | 30K | 10 批 × (8K in / 3K out) |
| **合计** | **~1.18M** | **~330K** | 清洗 + 评估 + 提取 |

**按参数计算**：

```
1000 条成本      = (1,180,000 × P_IN + 330,000 × P_OUT) / 1_000_000
10 万条/月成本   = 1000 条成本 × 100
```

> 历史版本此处给出过固定美元总额（$1,440 / $849 / $3,600 等），因单价未冻结、且混用了不同模型口径，
> 已全部删除；需要具体金额时按上式代入 `P_IN` / `P_OUT`。

## 2. 成本预算

### 2.1 单条对话处理成本（LLM-only 口径）

**数据清洗 Agent**：
```
输入 token: ~450 (Prompt 300 + 数据 150)
输出 token: ~100 (JSON 结构化数据)

单条成本 = (450 × P_IN + 100 × P_OUT) / 1_000_000
```

**质量评估 Agent**：
```
输入 token: ~650 (Prompt 400 + 对话 150 + 知识库 100)
输出 token: ~200 (评估结果)

单条成本 = (650 × P_IN + 200 × P_OUT) / 1_000_000
```

**知识提取 Agent**（批量处理 100 条）：
```
输入 token: ~8000 (Prompt 500 + 100 条对话 7500)
输出 token: ~3000 (FAQ 列表)

每批成本 = (8000 × P_IN + 3000 × P_OUT) / 1_000_000
每条成本 = 每批成本 / 100
         = (80 × P_IN + 30 × P_OUT) / 1_000_000
```

**总计（LLM-only）**：
```
单条对话完整处理成本（清洗 + 评估 + 提取）
= ((450 + 650 + 80) × P_IN + (100 + 200 + 30) × P_OUT) / 1_000_000
= (1180 × P_IN + 330 × P_OUT) / 1_000_000
```

**示例**：当 `P_IN = $a`、`P_OUT = $b` 时，单条成本 = `(1180a + 330b) / 1_000_000` USD
（⚠️ `a` / `b` 为占位，非真实单价）。

### 2.2 月度成本预算（含基础设施口径）

> LLM 部分按 §0 公式代入；基础设施为**估算区间**，按云厂商当期报价调整。

### 2.3 年度成本预算

**通用公式（中型企业 10 万条/月为例）**：

```
月 LLM 成本   = (118,000,000 × P_IN + 33,000,000 × P_OUT) / 1_000_000
月基础设施    = $325–435（估算区间中值 $380）
年 LLM 成本   = 月 LLM 成本 × 12
年基础设施    = 月基础设施 × 12
年度总成本    = 年 LLM 成本 + 年基础设施

含基础设施的单条成本 = 年度总成本 / 1,200,000
```

> ⚠️ 待 `P_IN` / `P_OUT` 冻结后回填具体金额；在此之前对外沟通只引用公式与口径，不引用总额。

### 3.2 成本追踪器实现

```python
# app/core/cost_tracker.py
from decimal import Decimal
from typing import Dict, Any
from datetime import datetime
import json

from loguru import logger

from app.core.config import settings

class CostTracker:
    """成本追踪器（单价来自配置，不写死）"""

    # ⚠️ 待确认：LLM_PRICE_INPUT_PER_MTOK / LLM_PRICE_OUTPUT_PER_MTOK
    # 需在 app/core/config.py 与 backend/.env.example 中新增（本文件按 §0 的 P_IN / P_OUT 命名）
    PRICING = {
        settings.DEFAULT_LLM_MODEL: {
            "input": Decimal(str(settings.LLM_PRICE_INPUT_PER_MTOK)),
            "output": Decimal(str(settings.LLM_PRICE_OUTPUT_PER_MTOK)),
        },
    }
    
    def __init__(self, db_session):
        self.db = db_session
    
    async def track(
        self,
        model: str,
        input_tokens: int,
        output_tokens: int,
        task_id: str = None,
        attempt: int = 0,
        user_id: str = None,
        datasource_id: str = None,
        agent_name: str = None,
        agent_version: str = None,
        duration: float = None,
        **kwargs
    ) -> Dict[str, Any]:
        """
        追踪成本

        Returns:
            {
                "input_cost": 0.000135,
                "output_cost": 0.000150,
                "total_cost": 0.000285,
                "total_tokens": 550
            }
        """
        
        # 获取定价（未登记的模型回落到默认模型单价，避免静默算错）
        if model not in self.PRICING:
            logger.warning(
                "未登记单价的模型 {}，回落到默认模型 {} 的单价",
                model, settings.DEFAULT_LLM_MODEL,
            )
            model = settings.DEFAULT_LLM_MODEL
        
        pricing = self.PRICING[model]
        
        # 计算成本（P_IN / P_OUT 均为 USD / 百万 token）
        input_cost = (Decimal(input_tokens) / Decimal(1_000_000)) * pricing["input"]
        output_cost = (Decimal(output_tokens) / Decimal(1_000_000)) * pricing["output"]
        total_cost = input_cost + output_cost

        # 幂等键：同一 task 的同一次尝试只记一次
        idempotency_key = f"{task_id or 'adhoc'}:{attempt}"
        
        # 记录到数据库（ON CONFLICT 保证重复调用不重复计费）
        await self.db.execute(
            """
            INSERT INTO llm_calls (
                user_id, datasource_id, task_id, attempt, idempotency_key,
                service, model, agent_name, agent_version,
                input_tokens, output_tokens, total_tokens,
                input_cost, output_cost, total_cost,
                duration
            ) VALUES (
                :user_id, :datasource_id, :task_id, :attempt, :idempotency_key,
                :service, :model, :agent_name, :agent_version,
                :input_tokens, :output_tokens, :total_tokens,
                :input_cost, :output_cost, :total_cost,
                :duration
            )
            ON CONFLICT (idempotency_key) DO NOTHING
            RETURNING id
            """,
            {
                "user_id": user_id,
                "datasource_id": datasource_id,
                "task_id": task_id,
                "attempt": attempt,
                "idempotency_key": idempotency_key,
                "service": "deepseek",
                "model": model,
                "agent_name": agent_name,
                "agent_version": agent_version,
                "input_tokens": input_tokens,
                "output_tokens": output_tokens,
                "total_tokens": input_tokens + output_tokens,
                "input_cost": float(input_cost),
                "output_cost": float(output_cost),
                "total_cost": float(total_cost),
                "duration": duration
            }
        )
        
        # 检查预警
        await self._check_alerts(user_id, float(total_cost))
        
        return {
            "input_cost": float(input_cost),
            "output_cost": float(output_cost),
            "total_cost": float(total_cost),
            "total_tokens": input_tokens + output_tokens
        }
    
    async def get_usage_stats(
        self,
        user_id: str = None,
        datasource_id: str = None,
        start_date: datetime = None,
        end_date: datetime = None
    ) -> Dict[str, Any]:
        """获取使用统计"""
        
        # 构建查询
        query = "SELECT "
        query += "SUM(input_tokens) as total_input_tokens, "
        query += "SUM(output_tokens) as total_output_tokens, "
        query += "SUM(total_tokens) as total_tokens, "
        query += "SUM(total_cost) as total_cost, "
        query += "COUNT(*) as request_count, "
        query += "AVG(duration) as avg_duration "
        query += "FROM llm_calls WHERE 1=1 "
        
        params = {}
        
        if user_id:
            query += "AND user_id = :user_id "
            params["user_id"] = user_id
        
        if datasource_id:
            query += "AND datasource_id = :datasource_id "
            params["datasource_id"] = datasource_id
        
        if start_date:
            query += "AND created_at >= :start_date "
            params["start_date"] = start_date
        
        if end_date:
            query += "AND created_at <= :end_date "
            params["end_date"] = end_date
        
        result = await self.db.fetch_one(query, params)
        
        return {
            "total_input_tokens": result["total_input_tokens"] or 0,
            "total_output_tokens": result["total_output_tokens"] or 0,
            "total_tokens": result["total_tokens"] or 0,
            "total_cost": float(result["total_cost"] or 0),
            "request_count": result["request_count"] or 0,
            "avg_duration": float(result["avg_duration"] or 0)
        }
    
    async def _check_alerts(self, user_id: str, cost: float):
        """检查成本预警（阈值与 §5.1 统一）"""
        
        if not user_id:
            return
        
        # 获取今日累计成本
        today_cost = await self._get_daily_cost(user_id)
        
        # 获取用户配额
        user = await self.db.fetch_one(
            "SELECT quota FROM users WHERE id = :user_id",
            {"user_id": user_id}
        )
        
        if not user:
            return
        
        # JSONB 字段可能以字符串形式返回，先反序列化
        quota = user["quota"]
        if isinstance(quota, str):
            quota = json.loads(quota)
        quota = quota or {}

        daily_limit = float(quota.get("daily_cost_limit", settings.DAILY_COST_LIMIT))
        if daily_limit <= 0:
            logger.warning("用户 {} 的 daily_cost_limit 非正数，跳过预警", user_id)
            return

        ratio = today_cost / daily_limit
        
        # 预警阈值（与 §5.1 / 06-成本超限降级策略.md 一致）
        if ratio >= 1.0:
            logger.error("用户 {} 超出每日成本限制：${:.2f} / ${:.2f}", user_id, today_cost, daily_limit)
            await self._send_alert(user_id, "DAILY_LIMIT_EXCEEDED", today_cost, daily_limit)
        elif ratio >= 0.8:
            logger.warning("用户 {} 接近每日成本限制：${:.2f} / ${:.2f}", user_id, today_cost, daily_limit)
            await self._send_alert(user_id, "DAILY_LIMIT_WARNING", today_cost, daily_limit)
```

```python
# app/agents/base.py
import asyncio

from langchain_core.callbacks import BaseCallbackHandler

from app.core.config import settings
from app.core.cost_tracker import CostTracker

class CostTrackingCallback(BaseCallbackHandler):
    """成本追踪回调（每次 LLM 调用落库 llm_calls）"""
    
    def __init__(
        self,
        cost_tracker: CostTracker,
        agent_name: str,
        task_id: str = None,
        attempt: int = 0,
        user_id: str = None,
        datasource_id: str = None
    ):
        self.cost_tracker = cost_tracker
        self.agent_name = agent_name
        self.task_id = task_id
        self.attempt = attempt
        self.user_id = user_id
        self.datasource_id = datasource_id
    
    def on_llm_end(self, response, **kwargs):
        """LLM 调用结束时追踪成本（同步回调，DB 写入异步调度）"""
        
        llm_output = response.llm_output or {}
        token_usage = llm_output.get("token_usage") or {}
        
        # 部分 provider 把用量放在 message.usage_metadata
        if not token_usage and response.generations:
            message = response.generations[0][0].message
            usage = getattr(message, "usage_metadata", None) or {}
            token_usage = {
                "prompt_tokens": usage.get("input_tokens", 0),
                "completion_tokens": usage.get("output_tokens", 0),
            }
        
        asyncio.create_task(
            self.cost_tracker.track(
                model=llm_output.get("model_name") or settings.DEFAULT_LLM_MODEL,
                input_tokens=token_usage.get("prompt_tokens", 0),
                output_tokens=token_usage.get("completion_tokens", 0),
                task_id=self.task_id,
                attempt=self.attempt,
                user_id=self.user_id,
                datasource_id=self.datasource_id,
                agent_name=self.agent_name,
            )
        )

# 使用
from app.agents.cleaning_agent import DataCleaningAgent

agent = DataCleaningAgent()
callback = CostTrackingCallback(
    cost_tracker=cost_tracker,
    agent_name="cleaning_agent",
    task_id=task_id,
    user_id=user_id,
    datasource_id=datasource_id
)

result = await agent.invoke(
    input_data,
    config={"callbacks": [callback]}
)
```

```python
# app/core/model_router.py
from app.core.config import settings


class ModelRouter:
    """模型路由器（模型 id 全部来自配置，业务代码不写死）"""

    SIMPLE = "simple"
    MEDIUM = "medium"
    COMPLEX = "complex"

    def route(self, task_complexity: str) -> str:
        """根据任务复杂度选择模型

        Args:
            task_complexity: 'simple' / 'medium' / 'complex'

        Returns:
            模型 id（取自配置）
        """
        if task_complexity == self.SIMPLE:
            # 简单任务：分类、简单提取 → 更小/更便宜的型号
            return settings.DEGRADED_LLM_MODEL
        # 中等 / 复杂任务：主模型
        return settings.DEFAULT_LLM_MODEL

    def estimate_complexity(self, task_type: str, data_size: int) -> str:
        """估算任务复杂度"""
        
        # 简单任务
        if task_type in ["classify", "extract_simple"]:
            return self.SIMPLE
        
        # 复杂任务
        if task_type in ["report", "deep_analysis"]:
            return self.COMPLEX
        
        # 根据数据量
        if data_size > 5000:
            return self.COMPLEX
        elif data_size > 1000:
            return self.MEDIUM
        else:
            return self.SIMPLE

# 使用示例
router = ModelRouter()

# 数据清洗（中等）
model = router.route("medium")
agent = DataCleaningAgent(model=model)

# 简单分类（简单）
model = router.route("simple")
classifier = ClassificationAgent(model=model)
```

|---|---|

### 4.3 缓存策略

**Redis 缓存相同输入的结果**：

```python
# app/core/caching.py
import hashlib
import json
from typing import Optional, Dict, Any

class ResultCache:
    """结果缓存"""
    
    def __init__(self, redis_client):
        self.redis = redis_client
        self.ttl = 3600  # 1 小时
    
    def _generate_key(self, input_data: Dict[str, Any]) -> str:
        """生成缓存键"""
        # 计算输入的哈希
        data_str = json.dumps(input_data, sort_keys=True)
        return f"agent_result:{hashlib.md5(data_str.encode()).hexdigest()}"
    
    async def get(self, input_data: Dict[str, Any]) -> Optional[Dict]:
        """获取缓存"""
        key = self._generate_key(input_data)
        cached = await self.redis.get(key)
        
        if cached:
            logger.info(f"缓存命中: {key}")
            return json.loads(cached)
        
        return None
    
    async def set(self, input_data: Dict[str, Any], result: Dict):
        """设置缓存"""
        key = self._generate_key(input_data)
        await self.redis.setex(
            key,
            self.ttl,
            json.dumps(result)
        )

# 在 Agent 中使用
class CachedAgent(BaseAgent):
    def __init__(self, cache: ResultCache):
        super().__init__()
        self.cache = cache
    
    async def invoke(self, input_data: Dict) -> Dict:
        # 1. 检查缓存
        cached = await self.cache.get(input_data)
        if cached:
            return cached
        
        # 2. 调用 Agent
        result = await super().invoke(input_data)
        
        # 3. 写入缓存
        await self.cache.set(input_data, result)
        
        return result
```

**节省**：重复请求 100% 节省成本

### 4.4 批处理

**原则**：批量处理能摊薄固定的 Prompt 开销（system prompt 只发一次），从而减少总 token 消耗。

**❌ 逐条处理**：
```python
# 1000 条数据，1000 次 API 调用
for item in items:
    result = agent.invoke(item)  # 每次约 500 tokens（含重复的 system prompt）
```

**token 消耗**：1000 × 500 = **500,000 tokens**

---

**✅ 批处理**：
```python
# 1000 条数据，10 次 API 调用（每次 100 条）
batch_size = 100
for i in range(0, len(items), batch_size):
    batch = items[i:i+batch_size]
    result = agent.invoke_batch(batch)  # 每次约 5000 tokens（system prompt 只发 1 次）
```

**token 消耗**：10 × 5000 = **50,000 tokens**

**成本**：`(50,000 × 分摊后的 P_IN/P_OUT) / 1_000_000` —— 比逐条减少约 **90% 的 token**。
> 注：批处理也更容易触发上下文长度上限，需配合 `ContextLengthExceededError` 的截断/拆批兜底（见 `07-Agent错误重试机制.md`）。

```python
# app/core/cost_alerts.py
class CostAlertManager:
    """成本预警管理器

    阈值是全项目**唯一口径**，06-成本超限降级策略.md 直接引用本表，不得另立数字。
    """
    
    ALERT_THRESHOLDS = {
        "warning": 0.80,     # 80%：预警通知，服务正常
        "throttled": 0.90,   # 90%：开始限流
        "degraded": 1.00,    # 100%：降级到更小/更便宜的模型
        "stopped": 1.20,     # 120%：停止 AI 调用
    }
    
    async def check_and_alert(
        self,
        user_id: str,
        current_cost: float,
        limit: float,
        period: str = "daily"
    ):
        """检查并发送预警"""
        
        if limit <= 0:
            logger.warning("{} 的 {} 限额非正数，跳过预警", user_id, period)
            return

        ratio = current_cost / limit
        thresholds = self.ALERT_THRESHOLDS
        
        if ratio >= thresholds["stopped"]:
            await self._send_alert(
                user_id,
                level="critical",
                message=f"成本已严重超限：${current_cost:.2f} / ${limit:.2f}",
                action="停止 AI 调用"
            )
            # 限制用户 API 调用
            await self._throttle_user(user_id)
        
        elif ratio >= thresholds["degraded"]:
            await self._send_alert(
                user_id,
                level="critical",
                message=f"成本已超限：${current_cost:.2f} / ${limit:.2f}",
                action="降级到更小/更便宜的模型"
            )
        
        elif ratio >= thresholds["throttled"]:
            await self._send_alert(
                user_id,
                level="warning",
                message=f"成本接近限额：${current_cost:.2f} / ${limit:.2f}",
                action="开始限流"
            )
        
        elif ratio >= thresholds["warning"]:
            await self._send_alert(
                user_id,
                level="warning",
                message=f"成本接近限额：${current_cost:.2f} / ${limit:.2f}",
                action="请注意控制使用"
            )
    
    async def _send_alert(
        self,
        user_id: str,
        level: str,

            user_id=user_id,
            type="cost_alert",
            level=level,
            message=message

        # 3. Webhook（如果配置）
        if user.webhook_url:
            await send_webhook(
                url=user.webhook_url,
                data={
                    "event": "cost_alert",
                    "level": level,
                    "message": message,
                    "timestamp": datetime.now().isoformat()
                }
            )
```

```python
# app/services/cost_analytics.py
class CostAnalytics:
    """成本分析服务"""
    
    async def generate_report(
        self,
        user_id: str,
        start_date: datetime,
        end_date: datetime
    ) -> Dict:
        """生成成本分析报告"""
        
        # 1. 总体统计
        total_stats = await self._get_total_stats(user_id, start_date, end_date)
        
        # 2. 按 Agent 分组
        by_agent = await self._get_by_agent(user_id, start_date, end_date)

        by_datasource = await self._get_by_datasource(user_id, start_date, end_date)
        
        # 4. 趋势分析
        trend = await self._get_trend(user_id, start_date, end_date)
        
        # 5. 优化建议
        recommendations = await self._generate_recommendations(
            total_stats, by_agent
        )
        
        return {
            "period": {
                "start": start_date,
                "end": end_date
            },
            "summary": {
                "total_cost": total_stats["total_cost"],
                "total_tokens": total_stats["total_tokens"],
                "total_requests": total_stats["request_count"],
                # 除零保护：无调用时返回 0 而不是抛异常
                "avg_cost_per_request": (
                    total_stats["total_cost"] / total_stats["request_count"]
                    if total_stats["request_count"] > 0
                    else 0.0
                )
            },
            "breakdown": {
                "by_agent": by_agent,
                "by_datasource": by_datasource
            },
            "trend": trend,
            "recommendations": recommendations
        }
    
    async def _generate_recommendations(
        self,
        total_stats: Dict,
        by_agent: List[Dict]
    ) -> List[str]:
        """生成优化建议"""
        
        recommendations = []

        # 高成本告警阈值：业务参数，不是模型单价（单价见 §0）
        high_cost_per_call_usd = 0.01

        # 检查是否有高成本 Agent
        for agent in by_agent:
            if agent["avg_cost"] > high_cost_per_call_usd:
                recommendations.append(
                    f"Agent '{agent['name']}' 平均成本较高 (${agent['avg_cost']:.4f}/次)，"
                    f"建议优化 Prompt 或使用更小的模型"
                )
        
        # 检查缓存命中率
        cache_hit_rate = await self._get_cache_hit_rate()
        if cache_hit_rate < 0.3:  # 低于 30%
            recommendations.append(
                f"缓存命中率较低 ({cache_hit_rate:.1%})，"
                f"建议启用更激进的缓存策略"
            )
        
        # 检查批处理使用
        batch_usage = await self._get_batch_usage_rate()
        if batch_usage < 0.5:  # 低于 50%
            recommendations.append(
                "批处理使用率较低，建议合并小批量请求以降低成本"
            )
        
        return recommendations
```
