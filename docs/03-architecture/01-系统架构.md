## 3. 数据模型设计

### 核心表结构

#### 1. 数据源表（data_sources）

```sql
CREATE TABLE data_sources (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(255) NOT NULL,
    type VARCHAR(50) NOT NULL,  -- 'customer_service', 'sales', etc.
    description TEXT,
    config JSONB,  -- 数据源配置
    status VARCHAR(50) DEFAULT 'active',
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    user_id UUID REFERENCES users(id)
);
```

#### 2. 原始数据表（raw_data）

```sql
CREATE TABLE raw_data (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    datasource_id UUID REFERENCES data_sources(id),
    raw_content JSONB NOT NULL,  -- 原始数据
    file_info JSONB,  -- 文件信息
    status VARCHAR(50) DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT NOW()
);
```

#### 3. 清洗后数据表（cleaned_data）

```sql
CREATE TABLE cleaned_data (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    datasource_id UUID REFERENCES data_sources(id),
    raw_data_id UUID REFERENCES raw_data(id),
    structured_data JSONB NOT NULL,  -- 标准化 JSON
    quality_score FLOAT,  -- 0-1
    metadata JSONB,
    created_at TIMESTAMP DEFAULT NOW()
);
```

#### 4. 分析结果表（analysis_results）

```sql
CREATE TABLE analysis_results (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    datasource_id UUID REFERENCES data_sources(id),
    data_id UUID REFERENCES cleaned_data(id),
    analysis_type VARCHAR(50),  -- 'quality', 'knowledge', 'insight'
    result JSONB NOT NULL,
    ai_model VARCHAR(100),
    confidence FLOAT,
    created_at TIMESTAMP DEFAULT NOW()
);
```

#### 5. 知识库表（knowledge_base）

```sql
CREATE TABLE knowledge_base (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    datasource_id UUID REFERENCES data_sources(id),
    question TEXT NOT NULL,
    answer TEXT NOT NULL,
    category VARCHAR(100),
    frequency INT DEFAULT 1,
    quality_score FLOAT,
    source_ids UUID[],  -- 来源数据 ID
    embedding VECTOR(1536),  -- 向量（用于相似度检索）
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 6. 用户表（users）

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255),
    name VARCHAR(100),
    role VARCHAR(50) DEFAULT 'user',
    created_at TIMESTAMP DEFAULT NOW(),
    last_login_at TIMESTAMP
);
```

## 4. API 设计

### RESTful API 规范

#### 基础路径

```
Base URL: http://localhost:8000/api/v1
```

#### 数据源管理

```http
# 创建数据源
POST /datasources
Body: {
  "name": "客服对话-2026年1月",
  "type": "customer_service",
  "description": "...",
  "config": {}
}

# 获取数据源列表
GET /datasources?page=1&limit=20

# 获取单个数据源
GET /datasources/{id}

# 更新数据源
PUT /datasources/{id}

# 删除数据源
DELETE /datasources/{id}
```

#### 数据导入

```http
# 上传文件
POST /datasources/{id}/upload
Content-Type: multipart/form-data
Body: file

# 获取导入状态
GET /datasources/{id}/import-status

# 触发数据清洗
POST /datasources/{id}/clean
```

#### 分析

```http
# 质量评估
POST /datasources/{id}/analyze/quality
Body: {
  "data_ids": [...],  // 可选，不传则全部
  "options": {}
}

# 获取评估结果
GET /datasources/{id}/analysis/quality?page=1

# 知识提取
POST /datasources/{id}/extract-knowledge

# 客户洞察
POST /datasources/{id}/analyze/insights
```

#### 知识库

```http
# 获取 FAQ
GET /datasources/{id}/knowledge/faq?category=产品

# 搜索知识库
GET /datasources/{id}/knowledge/search?q=退款

# 获取知识盲区
GET /datasources/{id}/knowledge/gaps
```

#### 报告

```http
# 生成报告
POST /datasources/{id}/reports
Body: {
  "type": "quality",  // quality / knowledge / insight
  "format": "pdf"     // pdf / excel / markdown
}

# 获取报告列表
GET /datasources/{id}/reports

# 下载报告
GET /reports/{report_id}/download
```

## 5. AI Agent 设计

### Agent 架构

#### 1. 数据清洗 Agent

```python
class DataCleaningAgent:
    """
    功能：
    - 解析非结构化数据
    - 去重（完全 + 相似度）
    - 标准化字段
    - 填充缺失值
    
    输入：raw_data
    输出：cleaned_data + quality_score
    """
    
    tools = [
        "parse_unstructured",  # 解析工具
        "deduplicate",         # 去重工具
        "normalize",           # 标准化工具
        "fill_missing"         # 填充工具
    ]
```

#### 2. 质量评估 Agent

```python
class QualityAssessmentAgent:
    """
    功能：
    - 评估准确性
    - 评估完整性
    - 检测幻觉
    - 评估礼貌度
    
    输入：conversation + knowledge_base
    输出：quality_scores + issues + suggestions
    """
    
    dimensions = [
        "accuracy",      # 准确性
        "completeness",  # 完整性
        "hallucination", # 幻觉检测
        "tone",          # 语气
        "compliance"     # 合规性
    ]
```

#### 3. 知识提取 Agent

```python
class KnowledgeExtractionAgent:
    """
    功能：
    - 提取高频问题
    - 提取标准答案
    - 聚类相似问题
    - 发现知识盲区
    
    输入：conversations
    输出：faq_list + knowledge_gaps
    """
    
    steps = [
        "extract_questions",   # 提取问题
        "extract_answers",     # 提取答案
        "cluster_similar",     # 聚类
        "find_gaps"            # 发现盲区
    ]
```

#### 4. 报告生成 Agent

```python
class ReportGenerationAgent:
    """
    功能：
    - 收集数据
    - AI 分析
    - 生成 Markdown
    - 导出多格式
    
    输入：datasource_id + report_type
    输出：report (pdf/excel/md)
    """
    
    report_types = [
        "quality",    # 质量报告
        "knowledge",  # 知识库报告
        "insight",    # 洞察报告
        "operations"  # 运营报告
    ]
```

## 6. 工作流设计（LangGraph）

### 数据处理工作流

```python
from langgraph.graph import StateGraph, END

workflow = StateGraph()

# 定义节点
workflow.add_node("upload", upload_data)
workflow.add_node("clean", clean_data_agent)
workflow.add_node("analyze", quality_assessment_agent)
workflow.add_node("extract", knowledge_extraction_agent)
workflow.add_node("report", report_generation_agent)

# 定义流程
workflow.set_entry_point("upload")
workflow.add_edge("upload", "clean")
workflow.add_edge("clean", "analyze")
workflow.add_edge("analyze", "extract")
workflow.add_edge("extract", "report")
workflow.add_edge("report", END)

# 编译
app = workflow.compile()
```
