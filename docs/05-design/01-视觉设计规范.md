## 一、设计原则

### 1.1 核心原则
- **专业可信**：B 端产品，强调数据准确性和可信度
- **清晰高效**：信息层级清晰，用户能快速定位关键数据
- **一致性**：整个系统保持视觉和交互一致性
- **可访问性**：符合 WCAG 2.1 AA 标准，支持深色模式

### 1.2 目标用户
- **客服团队负责人**：需要快速看到核心指标和问题
- **数据分析师**：需要详细的数据视图和导出功能
- **AI 训练师**：需要清晰的知识库管理界面

## 三、字体系统

### 3.1 字体族（Font Family）

```css
/* 西文字体 */
--font-sans: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Roboto', sans-serif;

/* 中文字体 */
--font-zh: 'PingFang SC', 'Microsoft YaHei', 'Noto Sans CJK SC', sans-serif;

/* 等宽字体（代码、数字） */
--font-mono: 'JetBrains Mono', 'Fira Code', 'Consolas', 'Courier New', monospace;

/* 组合字体栈 */
--font-family: var(--font-sans), var(--font-zh);
```

### 3.2 字体大小（Font Size）

| 名称 | 大小 | 行高 | 用途 |
|------|------|------|------|
| `text-xs` | 12px | 16px | 辅助说明、标签 |
| `text-sm` | 14px | 20px | 表格文本、次要文本 |
| `text-base` | 16px | 24px | 正文文本 |
| `text-lg` | 18px | 28px | 小标题、重要信息 |
| `text-xl` | 20px | 28px | 卡片标题 |
| `text-2xl` | 24px | 32px | 页面副标题 |
| `text-3xl` | 30px | 36px | 页面主标题 |
| `text-4xl` | 36px | 40px | 超大标题（仅首页） |

### 3.3 字重（Font Weight）

| 名称 | 值 | 用途 |

### 4.1 间距单位（基于 4px 网格）

| Token | 值 | 用途 |
|-------|-----|------|
| `spacing-1` | 4px | 紧凑间距 |
| `spacing-2` | 8px | 小间距 |
| `spacing-3` | 12px | 默认内边距 |
| `spacing-4` | 16px | **标准间距**（最常用） |
| `spacing-5` | 20px | 卡片内边距 |
| `spacing-6` | 24px | 卡片间距 |
| `spacing-8` | 32px | 区块间距 |
| `spacing-10` | 40px | 大区块间距 |
| `spacing-12` | 48px | 超大间距 |
| `spacing-16` | 64px | 页面顶部间距 |

### 4.2 常用组合

```css
/* 卡片 */
padding: 24px;  /* spacing-6 */
margin-bottom: 16px;  /* spacing-4 */

/* 按钮 */
padding: 12px 20px;  /* spacing-3 spacing-5 */

/* 表单 */
margin-bottom: 16px;  /* spacing-4，表单项间距 */

/* 页面容器 */
padding: 32px 24px;  /* spacing-8 spacing-6 */
```

## 八、动效系统（Transitions）

### 8.1 过渡时长

| Token | 值 | 用途 |
|-------|-----|------|
| `duration-75` | 75ms | 极快（Hover） |
| `duration-150` | 150ms | **默认**（按钮、卡片） |
| `duration-300` | 300ms | 中速（抽屉、折叠） |
| `duration-500` | 500ms | 慢速（模态框） |

### 8.2 缓动函数（Easing）

```css
--ease-in: cubic-bezier(0.4, 0, 1, 1);  /* 淡入 */
--ease-out: cubic-bezier(0, 0, 0.2, 1);  /* 淡出（推荐） */
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);  /* 平滑（默认） */
```

### 8.3 常用动效

```css
/* Hover 效果 */
transition: all 150ms ease-out;

/* 模态框进入 */
transition: opacity 300ms ease-in-out, transform 300ms ease-out;

/* 加载动画 */
animation: spin 1s linear infinite;
```

## 九、响应式断点（Breakpoints）

| 断点 | 宽度 | 设备 |
|------|------|------|
| `xs` | < 640px | 手机竖屏 |
| `sm` | ≥ 640px | 手机横屏 |

**设计优先级**: `lg` (1280px) → `md` (768px) → `xs` (375px)

## 十一、可访问性（A11y）

### 11.1 对比度要求（WCAG 2.1 AA）
- **正文文本**（< 18px）：对比度 ≥ 4.5:1
- **大文本**（≥ 18px 或 14px bold）：对比度 ≥ 3:1
- **图标、图形**：对比度 ≥ 3:1

**验证工具**: [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)

### 11.2 焦点状态
```css
/* 键盘焦点环 */
focus:ring-2 focus:ring-primary-500 focus:ring-offset-2
```

### 11.3 屏幕阅读器支持
- 所有交互元素添加 `aria-label`
- 图标按钮添加 `aria-describedby`
- 表单错误添加 `aria-invalid` + `aria-errormessage`
