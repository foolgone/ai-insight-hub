## 0. 一页速览

**一句话**：先把「路由 + 请求层 + 鉴权 + 布局骨架」四块地基打牢并冻结"设计稿 ↔ 后端接口"的口径冲突，再按 **登录 → 数据源 → 清洗 → Dashboard/评估 → 知识/报告** 的数据依赖顺序交付页面；组件跟着消费方分批落地（不先做全 35 个再做页面），每个页面与测试、响应式、可访问性同批交付。
