#### 菜单项规范

## 3.1 登录页（/login）

### 布局
```
┌──────────────────────────────────────────┐
│                                          │
│          [Logo + Slogan]                 │
│                                          │
│    ┌──────────────────────────┐         │
│    │  欢迎使用 AI Insight Hub │         │
│    │                          │         │
│    │  [邮箱输入框]            │         │
│    │  [密码输入框]            │         │
│    │  [记住我] [忘记密码?]    │         │
│    │  [登录按钮 - 全宽]       │         │
│    │                          │         │
│    │  ──── 或 ────            │         │
│    │  [SSO 登录按钮]          │         │
│    └──────────────────────────┘         │
│                                          │
└──────────────────────────────────────────┘
```

### 视觉规范
- **背景**: 渐变背景（`primary-50` → `primary-100`）
- **登录卡片**: 宽度 400px，居中，`shadow-xl`
- **Logo**: 顶部居中，64px 高度
- **Slogan**: Logo 下方，`text-gray-600`

### 交互规范
1. **表单验证**: 失败时输入框底部显示红色错误提示
2. **登录中**: 按钮显示 Spinner，禁用输入
3. **成功**: Toast 提示 "登录成功"，跳转 Dashboard
4. **失败**: Toast 提示错误信息（如 "密码错误"）

### 状态映射
| 状态 | 按钮文本 | 按钮状态 | 输入框 |
|------|---------|---------|--------|
| 默认 | "登录" | 启用 | 可编辑 |
| 验证中 | "验证中..." | 禁用 | 禁用 |
| 登录中 | "登录中..." + Spinner | 禁用 | 禁用 |

### 组件清单
1. **页面标题 + 新建按钮**
   - 新建按钮: `variant="primary"`，右侧固定

2. **筛选栏**
   - 搜索框: 320px，占位符 "搜索数据源名称"
   - 平台筛选: 下拉选择（全部/淘宝/京东/拼多多/抖音）
   - 状态筛选: 下拉选择（全部/已连接/未连接/错误）

3. **数据源卡片列表**
   - 组件: `DataSourceCard`
   - 布局: 单列，垂直堆叠
   - 内容:
     - 状态指示器（左侧圆点，绿色=已连接，红色=错误，灰色=未连接）
     - 数据源名称（`text-lg`，`font-semibold`）
     - 元信息（数据量、最后同步时间）
     - 操作菜单（右上角，下拉菜单）

4. **操作菜单**（点击展开）
   - 查看详情
   - 编辑配置
   - 立即同步
   - 删除（红色，需二次确认）

5. **分页器**
   - 底部居中
   - 显示: 当前页/总页数

### 新建数据源流程
1. 点击 "新建数据源" → 打开 Drawer（右侧滑入）
2. **步骤 1**: 选择平台（图标卡片选择）
3. **步骤 2**: 填写配置（API 密钥、店铺 ID）
4. **步骤 3**: 测试连接
5. **步骤 4**: 保存

   - 列: 任务名称、数据源、状态、进度、操作
   - 进度: 进度条 + 百分比 + 剩余时间
   - 状态徽章: 进行中（蓝）、已完成（绿）、失败（红）

3. **操作列**
   - 进行中: [暂停] [取消]
   - 已完成: [查看结果] [下载]
   - 失败: [查看日志] [重试]

### 新建清洗任务流程
1. 点击 "新建清洗任务" → 打开 Modal（600px）
2. **步骤 1**: 选择数据源
3. **步骤 2**: 选择清洗规则（多选）
   - 去重
   - 去除空值
   - 敏感信息脱敏
   - 格式标准化
4. **步骤 3**: 预览（显示前 10 条清洗前后对比）
5. **步骤 4**: 确认启动

## 四、响应式设计规范

### 4.1 桌面端（≥ 1280px）
- Sidebar 固定展开
- 内容区最大宽度 1600px，居中显示
- 卡片/表格使用完整布局

### 4.2 平板端（768–1279px）
- Sidebar 可折叠
- 统计卡片从 4 列 → 2 列
- 图表从 2 列 → 1 列

### 4.3 移动端（< 768px）
- Sidebar 改为抽屉（点击汉堡菜单打开）
