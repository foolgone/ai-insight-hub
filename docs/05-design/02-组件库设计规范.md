## 一、组件库概述

### 1.1 技术选型
- **基础库**: React 18（**纯 JS，文件后缀 `.jsx`，不使用 TypeScript**）
- **UI 框架**: Radix UI（无样式，完全可定制）— 规划中，**当前 `package.json` 未安装**
- **样式方案**: **TailwindCSS 3 为唯一主方案**（详见 1.3）
- **图标库**: `react-icons`（已安装）；设计稿层面推荐 Lucide Icons 图标集
- **动画库**: Framer Motion（可选，复杂交互；**当前未安装**）

> **关于 Props 类型**：项目是纯 JS，本文档中所有 Props「接口」均以 **JSDoc `@typedef`** 表达（供 IDE 提示与阅读），运行时不做类型检查。禁止在实现文件里写 `interface` / `.ts` / `.tsx`。

### 1.2 组件分类

| 类别 | 组件数量 | 说明 |
|------|---------|------|
| **基础组件** | 12 个 | 按钮、输入框、选择器等 |
| **数据展示** | 8 个 | 表格、卡片、统计面板等 |
| **反馈组件** | 6 个 | Toast、Modal、Loading 等 |
| **导航组件** | 4 个 | Sidebar、Breadcrumb、Tabs 等 |
| **业务组件** | 5 个 | 数据源卡片、Agent 状态等 |

**总计**: 35 个组件

### 1.3 样式方案边界（TailwindCSS 与 CSS Modules）

**结论：默认只用 TailwindCSS，不引入 CSS Modules。** 理由：设计 Token 已全部落进 `frontend/tailwind.config.js`，用 CSS Modules 会绕开 token（硬编码色值），产生两套样式来源。

| 场景 | 用什么 | 说明 |
|------|-------|------|
| 布局、间距、颜色、字体、圆角、阴影、响应式 | **Tailwind 类名** | 覆盖 95% 以上的样式需求 |
| 组件变体（primary/secondary/danger…） | **Tailwind 类名 + `clsx` 条件拼接** | `clsx` 已安装 |
| 第三方库 DOM 结构无法挂类名时的样式覆盖 | **全局 CSS（`src/index.css`）+ 限定作用域的选择器** | 需在 PR 中说明理由 |
| 需要复杂 `@keyframes`、`clip-path`、多层伪元素动画 | **`@layer utilities` 里自定义 Tailwind 工具类** | 写在 `src/index.css`，仍受 Tailwind 构建管辖 |

**禁止事项**：
1. ❌ 同一组件同时用 Tailwind 和 CSS Modules（会出现「改了 class 不生效、优先级打架」）。
2. ❌ 在 CSS 里硬编码色值（`#3B82F6`），必须用 token（`theme('colors.primary.500')` 或 Tailwind 类名）。
3. ❌ 引入 CSS-in-JS 运行时库（styled-components / emotion）——与 Tailwind 的构建期方案冲突。

> 若未来确需 CSS Modules（例如移植一个带复杂样式的第三方组件），须先在此表登记「组件名 + 理由 + 作用域文件」，否则视为不符合规范。

## 二、基础组件（12 个）

### 2.1 Button（按钮）

#### 变体（Variants）
```js
/** @typedef {'primary'|'secondary'|'outline'|'ghost'|'danger'} ButtonVariant */
```

| 变体 | 用途 | 示例 |
|------|------|------|
| `primary` | 主操作（蓝色填充） | 提交、保存 |
| `secondary` | 次要操作（灰色填充） | 取消、返回 |
| `outline` | 轻量操作（边框） | 导出、筛选 |
| `ghost` | 极轻操作（无边框） | 图标按钮 |
| `danger` | 危险操作（红色） | 删除、停止 |

#### 尺寸（Sizes）
| 尺寸 | 高度 | 内边距 | 字体 | 用途 |
|------|------|--------|------|------|
| `sm` | 32px | `8px 12px` | 14px | 表格行内按钮 |
| `md` | 40px | `12px 20px` | 16px | **默认尺寸** |
| `lg` | 48px | `16px 24px` | 18px | 首页 CTA |

#### 状态
- **Default**: 默认状态
- **Hover**: 颜色加深 10%，`shadow-md`
- **Active**: 颜色加深 20%
- **Disabled**: 透明度 50%，`cursor-not-allowed`
- **Loading**: 显示 Spinner，禁用点击

#### API 设计
```js
/**
 * @typedef {Object} ButtonProps
 * @property {ButtonVariant} [variant='primary'] 变体
 * @property {'sm'|'md'|'lg'} [size='md'] 尺寸
 * @property {boolean} [disabled=false] 禁用
 * @property {boolean} [loading=false] 加载中（显示 Spinner 并禁用点击）
 * @property {React.ReactNode} [icon] 左侧图标
 * @property {React.ReactNode} [iconRight] 右侧图标
 * @property {boolean} [fullWidth=false] 占满父容器宽度
 * @property {() => void} [onClick] 点击回调
 * @property {React.ReactNode} children 按钮内容
 */
```

#### 视觉规范（MVP 实现口径）

## 七、组件开发规范

### 7.1 文件结构

通用组件用单目录；布局/鉴权/通用件/业务组件/页面域组件按功能分组（与前端计划 T-4 一致）：

```
src/components/
├── Button/                      # 通用组件：<Name>/{<Name>.jsx, <Name>.test.jsx, index.js}
│   ├── Button.jsx
│   ├── Button.test.jsx
│   └── index.js
├── layout/                      # AppLayout / Header / Sidebar / Breadcrumb
├── auth/                        # ProtectedRoute / RequireRole
├── common/                      # ErrorBoundary / PageLoading / AsyncState / Markdown
├── business/                    # DataSourceCard / AgentStatusBadge / QualityScoreDisplay / KnowledgeEntryCard / ReportPreview
├── datasource/ cleaning/ quality/ knowledge/ reports/   # 页面域组件
└── Chart/                       # 图表容器（含 Chart.test.jsx）
```

### 7.2 命名规范
- **组件**: PascalCase（`DataTable`）
- **Props typedef**: `ComponentNameProps`（JSDoc）
- **变体 typedef**: `ComponentNameVariant`（JSDoc）
- **样式**: 只用 Tailwind 类名；条件拼接用 `clsx`

### 7.3 JS 代码约定（无 TypeScript）
- 所有 Props 用 **JSDoc `@typedef` + `@property`** 声明，写在组件文件顶部或 `types.js`
- 组件签名统一为 `export function Button({ variant = 'primary', ... })`，**默认值写在解构里**
- 用 `prop-types` 做运行时校验属于**可选**（当前 `package.json` 未安装，且 `.eslintrc.json` 已关闭 `react/prop-types`），**不作为门禁**
- 禁止出现：`interface`、`type X =`、`.ts` / `.tsx` 文件、泛型语法 `<T>`
- 导出的组件一律具名导出（便于 Vitest 按名导入），默认导出仅用于页面级组件

### 7.4 可访问性要求
- [ ] 键盘导航支持
- [ ] ARIA 属性完整
- [ ] 焦点管理
- [ ] 屏幕阅读器优化
