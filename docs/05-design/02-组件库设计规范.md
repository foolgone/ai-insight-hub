## 一、组件库概述

### 1.1 技术选型
- **基础库**: React 18 + TypeScript 5
- **UI 框架**: Radix UI（无样式，完全可定制）
- **样式方案**: TailwindCSS 3 + CSS Modules（复杂组件）
- **图标库**: Lucide React
- **动画库**: Framer Motion（可选，复杂交互）

### 1.2 组件分类

| 类别 | 组件数量 | 说明 |
|------|---------|------|
| **基础组件** | 12 个 | 按钮、输入框、选择器等 |

## 二、基础组件（12 个）

### 2.1 Button（按钮）

#### 变体（Variants）
```tsx
type ButtonVariant = 'primary' | 'secondary' | 'outline' | 'ghost' | 'danger';
```

| 变体 | 用途 | 示例 |
|------|------|------|
| `primary` | 主操作（蓝色填充） | 提交、保存 |
| `secondary` | 次要操作（灰色填充） | 取消、返回 |
| `outline` | 轻量操作（边框） | 导出、筛选 |
| `ghost` | 极轻操作（无边框） | 图标按钮 |
| `danger` | 危险操作（红色） | 删除、停止 |

#### 尺寸（Sizes）
| 尺寸 | 高度 | 内边距 | 字体 | 用途 |
|------|------|--------|------|------|
| `sm` | 32px | `8px 12px` | 14px | 表格行内按钮 |
| `md` | 40px | `12px 20px` | 16px | **默认尺寸** |
| `lg` | 48px | `16px 24px` | 18px | 首页 CTA |

#### 状态
- **Default**: 默认状态
- **Hover**: 颜色加深 10%，`shadow-md`
- **Active**: 颜色加深 20%
- **Disabled**: 透明度 50%，`cursor-not-allowed`
- **Loading**: 显示 Spinner，禁用点击

#### API 设计
```tsx
interface ButtonProps {
  variant?: 'primary' | 'secondary' | 'outline' | 'ghost' | 'danger';
  size?: 'sm' | 'md' | 'lg';
  disabled?: boolean;
  loading?: boolean;
  icon?: React.ReactNode;  // 左侧图标
  iconRight?: React.ReactNode;  // 右侧图标
  fullWidth?: boolean;
  onClick?: () => void;
  children: React.ReactNode;
}
```

### 2.2 Input（输入框）

#### 变体
- **Default**: 标准输入框
- **Search**: 左侧搜索图标
- **Password**: 右侧切换显示按钮
- **Number**: 右侧上下调整按钮

#### 状态
| 状态 | 边框颜色 | 说明 |
|------|---------|------|
| Default | `gray-300` | 默认 |
| Focus | `primary-500` | 聚焦时 + `ring-2` |
| Error | `error-500` | 验证失败 |
| Disabled | `gray-200` | 禁用状态 |

#### API 设计
```tsx
interface InputProps {
  type?: 'text' | 'email' | 'password' | 'number' | 'search';
  placeholder?: string;
  value?: string;
  onChange?: (value: string) => void;
  error?: string;  // 错误提示
  helperText?: string;  // 辅助说明
  prefix?: React.ReactNode;  // 前缀（图标）
  suffix?: React.ReactNode;  // 后缀
  disabled?: boolean;
  required?: boolean;
}
```

## 三、数据展示组件（8 个）

### 3.1 Table（表格）

#### 视觉规范
- **表头**: `bg-gray-50`，`font-semibold`，`text-gray-700`
- **行高**: 56px（默认），48px（紧凑模式）
- **边框**: `border-gray-200`
- **Hover**: `bg-gray-50`
- **选中行**: `bg-primary-50`

#### 功能特性
- [x] 排序（点击列头）
- [x] 分页（页码 + 每页条数）
- [x] 多选（Checkbox）
- [x] 固定列（左侧固定）
- [x] 展开行（嵌套数据）
- [x] 空状态
- [x] 加载状态（Skeleton）

#### API 设计
```tsx
interface TableProps {
  columns: Array<{
    key: string;
    title: string;
    dataIndex: string;
    width?: number;
    sortable?: boolean;
    fixed?: 'left' | 'right';
    render?: (value: any, record: any) => React.ReactNode;
  }>;
  dataSource: Array<Record<string, any>>;
  rowKey: string;
  loading?: boolean;
  pagination?: {
    current: number;
    pageSize: number;
    total: number;
    onChange: (page: number, pageSize: number) => void;
  };
  rowSelection?: {
    selectedRowKeys: string[];
    onChange: (keys: string[]) => void;
  };
}
```

### 3.2 Card（卡片）

```tsx
  bordered?: boolean;
  loading?: boolean;

}
```

### 3.3 StatCard（统计卡片）

#### 视觉规范
- **布局**: 左侧图标 + 右侧数据
- **主数值**: `text-3xl`，`font-bold`
- **标题**: `text-sm`，`text-gray-600`
- **趋势**: 右侧箭头 + 百分比（绿色↑ / 红色↓）

#### API 设计
```tsx
interface StatCardProps {
  title: string;
  value: string | number;
  icon: React.ReactNode;
  trend?: {
    value: number;  // 百分比，如 12.5
    direction: 'up' | 'down';
  };
  color?: 'primary' | 'success' | 'warning' | 'error';
}
```

#### 变体
```tsx
type ToastVariant = 'success' | 'error' | 'warning' | 'info';
```

#### 视觉规范
- **位置**: 右上角，距离边缘 24px
