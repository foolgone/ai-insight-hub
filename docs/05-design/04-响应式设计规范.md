## 一、断点系统

### 1.1 断点定义

| 断点名称 | 最小宽度 | 设备类型 | 主要用途 |
|---------|---------|---------|---------|
| `xs` | 0px | 手机竖屏 | 0–639px |
| `sm` | 640px | 手机横屏 | 640px–767px |
| `md` | 768px | 平板竖屏 | 768px–1023px |
| `lg` | 1024px | 平板横屏/笔记本 | 1024px–1279px |
| `xl` | 1280px | 桌面显示器 | 1280px–1535px |
| `2xl` | 1536px | 大屏显示器 | 1536px+ |

> **`xs` 的落地方式**：Tailwind 默认没有 `xs`，本项目已在 `frontend/tailwind.config.js` 的 `theme.extend.screens` 中显式定义为 `xs: '0px'`（事实源为该文件，见 `01-视觉设计规范.md` 12.2）。
> 因此 `xs:*` 前缀的类名（如 `xs:grid-cols-1`）在**任何宽度**都生效，实际作用等价于「默认值 + 让 `sm:` 覆盖它」。不要把它理解为「只在 0–639px 生效」。

### 1.2 设计优先级

**桌面优先（Desktop First）策略**

1. **主设计**: `xl` (1280px) — 桌面端完整体验
2. **次设计**: `md` (768px) — 平板端适配
3. **补充设计**: `xs` (375px 为**典型值**，实际区间 0–639px) — 移动端适配

### 1.3 断点档位与栅格列数（唯一定义，其他文档引用此处）

| 档位 | 宽度区间 | 统计卡片列数 | 图表列数 | 表格形态 |
|------|---------|-------------|---------|---------|
| `xs` / `sm` | 0–767px | 1 列（sm 起 2 列） | 1 列 | 卡片列表 |
| `md` | 768–1023px | **2 列** | 1 列 | 简化表格（保留 3–5 个核心列） |
| `lg` 及以上 | ≥ 1024px | **4 列** | 2 列 | 完整表格 |

> 该映射与 `03-页面设计规范.md` 第四章一致：**平板 md（768–1023）统计卡片 2 列；≥ lg（1024）4 列**。
> 注意 Sidebar 的「固定/折叠」阈值是 `xl`（1280px），与栅格列数阈值（`lg` 1024px）**不是同一个档位**——1024–1279px 属于「4 列卡片 + 可折叠 Sidebar」的组合，这是预期行为，不是冲突。

## 三、组件响应式规范

### 3.1 Header（导航栏）

| 断点 | 高度 | Logo | 搜索框 | 通知/头像 |
|------|------|------|--------|----------|
| `xs` | 56px | 仅图标 | 隐藏 | 显示 |
| `sm` | 56px | 图标+文字 | 隐藏 | 显示 |
| `md` | 64px | 图标+文字 | 显示（240px） | 显示 |
| `lg` | 64px | 图标+文字 | 显示（280px） | 显示 |
| `xl` | 64px | 图标+文字 | 显示（320px） | 显示 |

**移动端特殊处理**：
- 左侧: 汉堡菜单按钮（点击打开 Sidebar 抽屉）
- 搜索: 右上角放大镜图标 → 点击展开全屏搜索

---

### 3.2 Sidebar（侧边栏）

#### 桌面端（`xl`，≥ 1280px）
- **默认状态**: 展开（240px）
- **可折叠**: 点击折叠按钮 → 64px（仅显示图标）
- **动画**: 300ms，`ease-in-out`

#### 平板端（`md`–`lg`，768–1279px）
- **默认状态**: 折叠（64px）
- **Hover 展开**: 鼠标悬停 → 240px（浮层）
- **固定展开**: 点击固定按钮 → 保持 240px

#### 移动端（< `md`，< 768px）
- **完全隐藏**: 不占据布局空间
- **抽屉模式**: 点击汉堡菜单 → 从左侧滑入（240px）
- **遮罩**: 半透明黑色背景，点击关闭抽屉

### 3.5 表格（Table）

#### 桌面端（≥ 1024px）
- **完整表格**: 显示所有列
- **固定表头**: 滚动时表头固定
- **横向滚动**: 内容超宽时横向滚动

#### 平板端（768–1023px）
- **隐藏次要列**: 如 "创建时间"、"操作人"
- **显示核心列**: 保留 3–5 个关键列

#### 移动端（< 768px）
- **卡片列表**: 表格改为卡片垂直堆叠
- **卡片布局**:
  ```
  ┌────────────────────────┐
  │ [图标] 标题             │
  │ 状态徽章               │
  │ 关键信息1 | 关键信息2  │
  │ [操作按钮...]          │
  └────────────────────────┘
  ```

**实现示例**：
```jsx
// 桌面端
<Table className="hidden lg:table" />

// 移动端
<div className="lg:hidden space-y-4">
  {data.map(item => <MobileCard key={item.id} data={item} />)}
</div>
```

### 8.3 虚拟滚动

**移动端长列表优化**（依赖 `@tanstack/react-virtual`，**当前 `package.json` 未安装**，需先补充依赖后再采用）：

```jsx
import { useRef } from 'react';
import { useVirtualizer } from '@tanstack/react-virtual';

function KnowledgeList({ items }) {
  const parentRef = useRef(null);

  const virtualizer = useVirtualizer({
    count: items.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 120,  // 估算项高度
  });

  return (
    <div ref={parentRef} className="h-screen overflow-auto">
      <div style={{ height: `${virtualizer.getTotalSize()}px` }}>
        {virtualizer.getVirtualItems().map(virtualItem => (
          <div
            key={virtualItem.index}
            style={{
              position: 'absolute',
              top: 0,
              left: 0,
              width: '100%',
              transform: `translateY(${virtualItem.start}px)`,
            }}
          >
            <KnowledgeCard data={items[virtualItem.index]} />
          </div>
        ))}
      </div>
    </div>
  );
}
```

## 十一、常见问题

### Q1: 如何判断当前断点？

**自定义 Hook**：
```jsx
// src/hooks/useMediaQuery.js
import { useEffect, useState } from 'react';

/**
 * 订阅一个 CSS 媒体查询。
 * @param {string} query 媒体查询字符串，如 '(max-width: 767px)'
 * @returns {boolean} 当前是否匹配
 */
export function useMediaQuery(query) {
  const [matches, setMatches] = useState(
    () => (typeof window !== 'undefined' && window.matchMedia(query).matches)
  );

  useEffect(() => {
    const media = window.matchMedia(query);
    const listener = (event) => setMatches(event.matches);

    setMatches(media.matches);
    media.addEventListener('change', listener);
    return () => media.removeEventListener('change', listener);
  }, [query]);

  return matches;
}

// 使用
const isMobile = useMediaQuery('(max-width: 767px)');
const isTablet = useMediaQuery('(min-width: 768px) and (max-width: 1023px)');
const isDesktop = useMediaQuery('(min-width: 1024px)');
```

### Q2: 如何处理深色模式？

**TailwindCSS 深色模式**：
```jsx
<div className="bg-white dark:bg-gray-900 text-gray-900 dark:text-white">
  内容
```

**配置** (`frontend/tailwind.config.js`，ESM 语法)：
```js
/** @type {import('tailwindcss').Config} */
export default {
  darkMode: 'class',  // 默认未设置时为 'media'（跟随系统）
  // ... 其余 token 见 01-视觉设计规范.md 12.2

```

> 当前仓库的 `tailwind.config.js` **未**设置 `darkMode`（等价于 `'media'`）。若要支持手动切换主题，需改为 `'class'` 并在 `<html>` 上切换 `dark` 类——属**待确认项**（确认方式：产品需求评审是否在 MVP 提供主题开关）。

```jsx
import { render, screen } from '@testing-library/react';
import { beforeAll, expect, test, vi } from 'vitest';
```
