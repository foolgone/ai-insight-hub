## 3. Prompt 规则

### 3.1 absence / mixed sentence

- “文档未提及/未说明/未规定/未涉及……” → `non_factual` / `absence`；
- absence：`support_status=null`、`evidence_refs=[]`；
- 禁止 `factual_claim + absence`；
- 禁止给 absence 标 supported 或附 evidence；
- 混合句必须拆成 factual 事实部分 + non_factual absence 部分；
- 示例：Q23 类“该时限是硬性要求，文档未提及例外”拆成两条。

### 3.2 evidence 必须直接支持 claim

- 逐字连续只是必要条件；
- quote 必须支持 claim 的谓词/条件/结论；
- 不得用“运费承担”支持“质量问题不受 7 天限制”；
- derived claim 必须引用推导前提；
- 找不到直接支持时判 `insufficient_evidence`；
- `condition` / `policy_scope` / `policy_relationship` 同样要求直接依据。
