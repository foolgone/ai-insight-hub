## 4. Faithfulness 变更

只增加 evidence 连续性规则：

- 一条 `evidence_ref` 只能引用一个连续子串；
- 不得把两段不相邻的原文拼成一条 `quote`；
- 不得跳过中间句、用省略号、跨段拼接、改写标点或补主语/谓词；
- 需要两个片段时，拆成两条 claim，或只选能独立支持该 claim 的最短连续片段；
- 模式级反例：

```text
Context C1: A。B。C。
Bad quote:  A。C。    # 跳过 B，不是连续子串 -> invalid
Good:       claim A -> "A。"；claim C -> "C。"
```

没有写 Q11/Qxx 案例 ID，没有改评分公式，没有改 Service。
