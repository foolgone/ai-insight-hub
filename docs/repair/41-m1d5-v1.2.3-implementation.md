## 3. 实现内容

### 3.1 共享 quote validator

新增 `backend/app/schemas/agents/rag_judge_evidence.py`：

- `build_context_map`：C1..Cn；
- `check_quote`：`quote.strip() in context.strip()`，错误码 `unknown_context_id` / `empty_quote` / `quote_not_found`；
- `check_claims_evidence`：按模型顺序返回 `QuoteCheck`；
- `format_quote_contract_error`：最多 5 条、总长 ≤2000，包含 claim_id/context_id/quote/context_excerpt/fix；
- `detect_mixed_absence`：clause-level 检测 factual + absence；
- `quote_validator_sha256()`：代码指纹；
- `QuoteContractError(ValueError)`。

Service `_v3_evidence_refs` 改为调用 `check_quote`；错误码、错误顺序、invalid 行为保持。v2 `_validate_v2_evidence` 未改。

### 3.2 Agent 预校验

`RagJudgeAgent`：

- `CONTRACT_REPAIR_VERSION = "v1.2.3"`；
- 仅 v1.2.3 + faithfulness 初始化 `contract_report`；
- `_validate_parsed` 在 score 校验前调用 `_validate_quote_contract`；
- 使用 `_active_input.contexts`；contexts 不可用 fail closed；
- quote 非连续 + supported 混合句 → `QuoteContractError`；
- insufficient 混合句 → `mixed_sentence_warnings`，不触发 repair；
- repair 成功/失败写 `passed_after_repair`、`final_errors`；
- `_repair_example` 增加 v1.2.3 专属示例；v1.2.0/1/2 不变。

### 3.3 Service 记录

- `_judge_config` 仅 v1.2.3 加 `contract_repair_version` / `quote_validator_sha256`；
- `_agent_contract_details` 在成功和失败分支写入 `details.agent_contract`；
- v1.2.3 invalid outcome（含 F_strict）保留首次错误、repair 次数与 final_errors。

### 3.4 Prompt

v1.2.3 F 增加：

- `quote` 只能从 contexts 复制，不能从 answer 加粗句/引号句/转述复制；
- 必须连续子串，不得省略；
- 找不到连续原文判 `insufficient_evidence`；
- 通用合成反例（不含 Q23/生鲜食品/fixture 原句）。
