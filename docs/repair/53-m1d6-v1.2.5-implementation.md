## 4. Patch v1.2.5

新增 `backend/app/schemas/agents/rag_judge_patch_v125.py`：

- `EvidenceFixV125`：`evidence_refs` 允许空数组（Schema 层）。
- `EvidenceRefusalV125`：`claim_ids` + `reason_code` + `reason`。
- `EvidencePatchV125`：`fixes` 与 `refusal` 互斥，必须二选一。

Agent `_apply_evidence_patch_v125`：

| 场景 | 结果 |
|---|---|
| fixes 覆盖全部 quote 错误 | 允许 |
| fixes 缺一个 / 多一个 / 重复 | `patch_incomplete` → invalid |
| refusal 覆盖全部 quote 错误 | `patch_refused` → invalid |
| refusal 缺一个 | `patch_refusal_incomplete` → invalid |
| refusal 多一个 / 重复 | `patch_refusal_invalid` → invalid |
| fixes + refusal 同时出现 | `patch_schema_invalid` → invalid |
| supported + `[]` | `patch_empty_refs_for_supported` → invalid |
| unsupported/insufficient + `[]` | 允许 |
| insufficient + 非空 | `patch_refs_for_insufficient` → invalid |
| 非连续 quote | `patch_quote_invalid` → invalid |
| conflict + supported + <2 条/嵌套 | `patch_conflict_refs_invalid` → invalid |
| unsupported + 非空 | 允许，记录 `patch_unsupported_quote_claims`，需 claim-level 人工复核 |

v1.2.4 的 `rag_judge_patch.py`、patch example、`_apply_evidence_patch` 逐字不变；v1.2.0–v1.2.4 回归测试全绿。
