## 二、通用规范

### 2.1 命名约定

#### 测试文件
- **格式**: `test_<module_name>.py`
- **示例**: `test_cleaning_agent.py`

#### 测试类
- **格式**: `Test<ClassName>`
- **示例**: `TestDataCleaningAgent`

#### 测试函数
- **格式**: `test_<function>_<scenario>_<expected_result>`
- **示例**: `test_parse_dialogue_with_valid_input_returns_dict`

### 2.2 AAA 模式

所有测试遵循 **Arrange-Act-Assert** 模式：

```python
def test_example():
    # Arrange（准备）- 设置测试数据和环境
    agent = DataCleaningAgent()
    input_data = {"raw": "用户: 退款"}
    
    # Act（执行）- 调用被测试的函数
    result = agent.parse(input_data)
    
    # Assert（断言）- 验证结果
    assert result["user_message"] == "退款"
```

### 2.3 测试独立性

- ✅ 每个测试独立运行
- ✅ 测试间无依赖顺序
- ✅ 使用 Fixture 隔离状态
- ❌ 避免共享可变状态

```python
# tests/unit/test_agents/test_cleaning_agent.py
import pytest
from app.agents.cleaning_agent import DataCleaningAgent
from app.schemas.dialogue import DialogueInput

class TestDataCleaningAgent:
    """数据清洗 Agent 测试"""
    
    @pytest.fixture
    def agent(self):
        """创建 Agent 实例"""
        return DataCleaningAgent()
    
    def test_parse_dialogue_with_valid_input_returns_structured_data(self, agent):
        """给定有效对话，解析应返回结构化数据"""
        # Arrange
        raw_dialogue = """
        用户: 订单何时发货？
        AI: 请提供订单号。
        """
        
        # Act
        result = agent.parse_dialogue(raw_dialogue)
        
        # Assert
        assert result["user_message"] == "订单何时发货？"
        assert result["ai_response"] == "请提供订单号。"
        assert "timestamp" in result
    
    def test_parse_dialogue_with_empty_input_raises_validation_error(self, agent):
        """给定空输入，解析应抛出验证错误"""
        # Arrange
        raw_dialogue = ""
        
        # Act & Assert
        with pytest.raises(ValueError, match="输入不能为空"):
            agent.parse_dialogue(raw_dialogue)
    
    @pytest.mark.parametrize("input_text,expected_user_msg", [
        ("用户: 退款", "退款"),
        ("用户：退款", "退款"),  # 全角冒号
        ("用户:退款", "退款"),   # 无空格
    ])
    def test_parse_user_message_handles_various_formats(
        self, agent, input_text, expected_user_msg
    ):
        """解析用户消息应支持多种格式"""
        result = agent.parse_dialogue(input_text + "\nAI: 已收到")
        assert result["user_message"] == expected_user_msg
    
    def test_clean_data_removes_sensitive_info(self, agent):
        """清洗数据应脱敏敏感信息"""
        # Arrange
        dialogue = {
            "user_message": "我的手机号是 13812345678",
            "ai_response": "已记录您的联系方式"
        }
        
        # Act
        result = agent.clean_data(dialogue)
        
        # Assert
        assert "138****5678" in result["user_message"]
        assert "13812345678" not in result["user_message"]
```

## 八、Fixture 管理

### 8.1 共享 Fixtures

```python
# tests/conftest.py
import pytest
from app.agents.cleaning_agent import DataCleaningAgent

@pytest.fixture(scope="session")
def app_config():
    """应用配置"""
    return {
        "database_url": "postgresql://test",
        "redis_url": "redis://test"
    }

@pytest.fixture(scope="function")
def cleaning_agent():
    """数据清洗 Agent（每个测试独立实例）"""
    return DataCleaningAgent()

@pytest.fixture(scope="module")
def sample_dialogues():
    """样例对话数据（模块级共享）"""
    return [
        {"user_message": "退款", "ai_response": "请提供订单号"},
        {"user_message": "发货", "ai_response": "预计明天发货"},
    ]
```

### 8.2 Fixture 作用域

| 作用域 | 说明 | 用途 |
|--------|------|------|
| `function` | 每个测试函数 | 默认，测试间隔离 |
| `class` | 每个测试类 | 类内共享 |
| `module` | 每个测试文件 | 文件内共享 |
| `session` | 整个测试会话 | 全局共享（慎用） |

## 十三、常见问题

### Q1: 如何测试私有方法？

**A**: 不直接测试私有方法，通过公共接口间接验证。

```python
# ❌ 差：直接测试私有方法
def test_private_method(agent):
    result = agent._internal_parse("data")
    assert result == "parsed"

# ✅ 好：通过公共方法测试
def test_public_method_uses_internal_logic(agent):
    result = agent.parse("data")  # 内部调用 _internal_parse
    assert result == "expected_output"
```

---

### Q2: 如何处理随机性？

**A**: 固定随机种子或 Mock 随机函数。

```python
# 方法 1：固定种子
import random
random.seed(42)

# 方法 2：Mock
@patch('random.randint')
def test_with_mock(mock_randint):
    mock_randint.return_value = 5
    result = function_using_random()
    assert result == expected_value
```

---

### Q3: 如何加速慢速测试？

**A**: 
1. Mock 外部依赖（API、数据库）
2. 使用内存数据库（SQLite）
3. 并行运行（`pytest-xdist`）
4. 分离慢速测试（标记为 `@pytest.mark.slow`）

```python
# 标记慢速测试
@pytest.mark.slow
def test_heavy_computation():
    pass

# 运行时排除慢速测试
pytest tests/unit -m "not slow"
```
