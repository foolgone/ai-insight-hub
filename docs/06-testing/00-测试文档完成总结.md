## 五、实施顺序建议

1. **补齐基础配置**：`backend/.coveragerc`、`frontend/vitest.config.js`、`frontend/src/test/setup.js`，并在 `frontend/package.json` 增加 `jsdom`、`@vitest/coverage-v8`
2. **后端单元测试**：从 Agent 纯逻辑（解析、脱敏、评分归一化）开始，逐模块补到 80%
3. **后端集成测试**：`docker-compose -f docker-compose.test.yml up -d` 起测试库，按 API 契约补用例
4. **前端组件测试**：组件落地一个补一个，先 `Button` / `Input` / `Table`
5. **Prompt 测试**：先做 golden 基线 + 结构断言，再接语义相似度，最后加成本预算
6. **E2E**：Phase 2 评估 Playwright 引入
