## 1. 复核方法

1. **代码统计**：文件数 / 行数 / 路由装饰器 / `__tablename__` / 测试文件，均用命令直接统计（附录 A）。
2. **测试采集**：后端 `pytest --collect-only` 得 439 个用例；前端完整跑一遍 `vitest run --reporter=json` 得 316 个用例。
3. **CI 核对**：逐行读 `.github/workflows/test.yml`，确认哪些门禁是真阻塞。
4. **未执行项**（明确声明局限）：后端 439 个用例需要 PostgreSQL/Redis，本环境未启动，故只采集不执行；覆盖率数字取 CI 门禁而非本地实测；`aria-label` 覆盖率未量化。
