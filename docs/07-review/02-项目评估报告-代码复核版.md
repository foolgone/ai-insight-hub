## 1. 复核方法

1. **代码统计**：文件数 / 行数 / 路由装饰器 / `__tablename__` / 测试文件，均用命令直接统计（附录 A）。
2. **测试采集**：后端 `pytest --collect-only` 得 454 个用例（默认排除 255 个 prompt 标记）；前端完整跑一遍 `vitest run --reporter=json` 得 321 个用例。
3. **CI 核对**：逐行读 `.github/workflows/test.yml`，确认哪些门禁是真阻塞。
4. **未执行项**（明确声明局限）：后端 454 个用例中，unit 本地执行通过；integration 需 PostgreSQL/Redis（CI 执行，本次在 VM 跑通认证 10 条与任务 SSE/种子等）。覆盖率数字取 CI 门禁而非本地实测；`aria-label` 覆盖率未量化。
