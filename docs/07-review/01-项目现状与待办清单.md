## 附录 A：取数命令（可复现）

```powershell
# A-1 后端测试用例数（需 backend/venv）
cd backend
.\venv\Scripts\python.exe -m pytest --collect-only -q

# A-2 前端测试用例数
cd frontend
npx vitest run --reporter=json --outputFile=.vitest-result.json
# 读取 numTotalTests / numPassedTests / numFailedTests

# A-3 接口数（以 FastAPI 路由表为准，排除 /docs /redoc /openapi 自动路由）
cd backend
.\venv\Scripts\python.exe -c @"
from app.main import app
excluded = ('/docs', '/redoc', '/openapi')
routes = [
    r for r in app.routes
    if getattr(r, 'methods', None) and not str(getattr(r, 'path', '')).startswith(excluded)
]
print('TOTAL', len(routes))  # 41
"@
# 口径：/api/v1 下 38 个 + 系统级 3 个（/、/health、/metrics）= 41

# A-4 表数
Select-String -Path backend\app\models\*.py -Pattern '__tablename__' | Measure-Object

# A-5 代码规模
Get-ChildItem backend\app -Recurse -File -Filter *.py |
  ForEach-Object { (Get-Content $_.FullName).Count } | Measure-Object -Sum
Get-ChildItem frontend\src -Recurse -File -Include *.js,*.jsx |
  Where-Object { $_.Name -notmatch '\.test\.' } |
  ForEach-Object { (Get-Content $_.FullName).Count } | Measure-Object -Sum
```

> 说明：`pytest --collect-only` 不连接数据库；前端全量测试的结果文件读取后应删除，避免入库。
