## 📜 核心原则

### 1. Agent-First 思维 🤖

**AI Agent 是一等公民，不是辅助工具**

```
传统开发：业务逻辑 + AI 辅助
AI 应用开发：AI Agent + 业务编排
```

**具体实践：**
- ✅ 核心能力由 Agent 实现（清洗、评估、提取、分析）
- ✅ 业务逻辑是 Agent 编排和协调
- ✅ Agent 可独立测试、优化、替换
- ❌ 不要把 AI 当成"调用的函数"
- ❌ 不要把 Prompt 硬编码在业务代码中

**架构体现：**
```python
# ❌ 错误：AI 作为辅助
def clean_data(data):
    # 100 行业务逻辑
    result = openai.chat(f"Clean this: {data}")  # AI 只是工具
    # 再 100 行业务逻辑
    return result

# ✅ 正确：Agent 为核心
class DataCleaningAgent:
    """独立的数据清洗 Agent"""
    def __init__(self, llm, tools, memory):
        self.agent = create_agent(llm, tools, memory)
    
    def clean(self, data):
        return self.agent.invoke({
            "input": data,
            "context": self.get_context()
        })
```

### 3. 流式优先 (Streaming-First) 🌊

**用户体验 > 完整响应**

**具体实践：**
- ✅ 所有 AI 输出支持流式返回
- ✅ 前端实时显示进度
- ✅ WebSocket 或 SSE (Server-Sent Events)
- ✅ 长任务支持取消

```python
# FastAPI + Streaming
@app.post("/api/agent/clean/stream")
async def clean_stream(data: DataSource):

            yield f"data: {json.dumps(chunk)}\n\n"
    
    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream"
    )
```

### 5. Human-in-the-Loop (HITL) 🤝

**AI 不是 100% 准确，人类审核是必要的**

**具体实践：**
- ✅ 低置信度结果 → 人工审核队列
- ✅ 批量审核界面
- ✅ 审核反馈 → 模型微调
- ✅ 异常检测 → 自动预警

**工作流设计：**
```
AI Agent 输出
    ↓
置信度评估
    ↓
    ├─ 高置信度 (>90%) → 自动通过
    ├─ 中置信度 (70-90%) → 人工审核队列
    └─ 低置信度 (<70%) → 自动拒绝 + 人工处理
```

**数据库设计：**
```sql
CREATE TABLE review_queue (
    id UUID PRIMARY KEY,
    agent_name VARCHAR(50),      -- 哪个 Agent 的输出
    input_data JSONB,            -- 输入
    agent_output JSONB,          -- AI 输出
    confidence_score FLOAT,      -- 置信度
    status VARCHAR(20),          -- pending/approved/rejected
    reviewer_id UUID,            -- 审核人
    reviewed_at TIMESTAMP,
    feedback TEXT                -- 反馈
);
```

### 6. 成本意识 (Cost-Aware) 💰

**Token 就是钱，优化是必须的**

**成本优化策略：**

#### 6.1 模型分级使用
```
简单任务 → 小模型（Haiku/GPT-3.5）
复杂任务 → 大模型（Opus/GPT-4）
```

```python
class AgentRouter:
    """根据任务复杂度选择模型"""
    
    def route(self, task):
        complexity = self.estimate_complexity(task)
        
        if complexity < 0.3:
            return "claude-haiku-5-5"    # 便宜快速
        elif complexity < 0.7:
            return "claude-sonnet-5-5"   # 平衡
        else:
            return "claude-opus-5-5"     # 复杂任务
```

#### 6.2 缓存策略
```python
from functools import lru_cache
import hashlib

class CachedAgent:
    def __init__(self, agent, redis_client):
        self.agent = agent
        self.cache = redis_client
    
    def invoke(self, input_data):
        # 计算输入哈希
        cache_key = hashlib.md5(
            json.dumps(input_data, sort_keys=True).encode()
        ).hexdigest()
        
        # 检查缓存
        if cached := self.cache.get(cache_key):
            return json.loads(cached)
        
        # 调用 Agent
        result = self.agent.invoke(input_data)
        
        # 写入缓存（24小时）
        self.cache.setex(cache_key, 86400, json.dumps(result))
        
        return result
```

```python
class CostTracker:
    """实时成本追踪"""
    
    PRICING = {
        "claude-opus-5-5": {
            "input": 15.00 / 1_000_000,   # $15/MTok
            "output": 75.00 / 1_000_000   # $75/MTok
        },
        "claude-sonnet-5-5": {
            "input": 3.00 / 1_000_000,
            "output": 15.00 / 1_000_000
        },
        "claude-haiku-5-5": {
            "input": 0.80 / 1_000_000,
            "output": 4.00 / 1_000_000
        }
    }
    
    def track(self, model, input_tokens, output_tokens):
        cost = (
            input_tokens * self.PRICING[model]["input"] +
            output_tokens * self.PRICING[model]["output"]
        )
        
        # 记录到数据库
        self.db.insert({
            "timestamp": now(),
            "model": model,
            "input_tokens": input_tokens,
            "output_tokens": output_tokens,
            "cost": cost
        })
        
        # 实时预警
        if self.get_daily_cost() > 100:  # $100/天
            self.alert("成本超限")
```

### 7. 安全第一 (Security-First) 🔒

**处理敏感数据，安全是红线**

#### 7.1 防止 Prompt 注入
```python
def sanitize_input(user_input: str) -> str:
    """清理用户输入，防止 Prompt 注入"""
    
    # 移除特殊指令
    forbidden = [
        "ignore previous instructions",
        "忽略之前的指令",
        "你现在是",
        "system:",
        "assistant:"
    ]
    
    for pattern in forbidden:
        user_input = user_input.replace(pattern, "[FILTERED]")
    
    return user_input

# 使用
clean_input = sanitize_input(user_input)
result = agent.invoke(clean_input)
```

#### 7.2 数据脱敏
```python
import re

class DataMasker:
    """敏感信息脱敏"""
    
    PATTERNS = {
        "phone": r"1[3-9]\d{9}",
        "email": r"[\w\.-]+@[\w\.-]+\.\w+",
        "id_card": r"\d{17}[\dXx]",
        "bank_card": r"\d{16,19}"
    }
    
    def mask(self, text: str) -> str:
        for key, pattern in self.PATTERNS.items():
            text = re.sub(
                pattern,
                lambda m: m.group()[:3] + "***" + m.group()[-2:],
                text
            )
        return text

# 在 AI 处理前脱敏
masked_data = masker.mask(original_data)
result = agent.invoke(masked_data)
```

#### 7.3 输出验证
```python
class OutputValidator:
    """验证 AI 输出，防止泄露敏感信息"""
    
    def validate(self, output: str) -> tuple[bool, str]:
        # 1. 检查是否包含训练数据
        if self.contains_memorized_data(output):
            return False, "输出包含训练数据"
        
        # 2. 检查是否泄露用户隐私
        if self.contains_pii(output):
            return False, "输出包含个人隐私信息"
        
        # 3. 检查是否有害内容
        if self.is_harmful(output):
            return False, "输出包含有害内容"
        
        return True, "OK"
```

### 9. 迭代优化 (Continuous Improvement) 🔄

**AI 应用不是一次开发完成，而是持续优化**

#### 9.1 数据飞轮
```
用户使用
    ↓
收集反馈（HITL）
    ↓
标注数据集
    ↓
微调/优化 Prompt
    ↓
部署新版本
    ↓
用户使用（回到开始）
```

#### 9.2 A/B 测试
```python
class ABTestingAgent:
    """支持 A/B 测试的 Agent"""
    
    def __init__(self):
        self.variants = {
            "A": Agent(prompt="prompts/v1.txt"),  # 原版本
            "B": Agent(prompt="prompts/v2.txt")   # 新版本
        }
        self.traffic_split = 0.5  # 50/50 分流
    
    def invoke(self, input_data, user_id):
        # 根据 user_id 一致性分流
        variant = "B" if hash(user_id) % 100 < 50 else "A"
        
        result = self.variants[variant].invoke(input_data)
        
        # 记录用于分析
        self.log_experiment(user_id, variant, result)
        
        return result
```

## 🏗️ 架构范式

### LangGraph 工作流编排

**AI Insight Hub 的核心是多 Agent 协作**

```python
from langgraph.graph import StateGraph

# 定义状态
class ProcessState(TypedDict):
    data_source_id: str
    raw_data: dict
    cleaned_data: dict
    evaluation_result: dict
    knowledge: dict
    report: dict
    status: str

# 构建工作流
workflow = StateGraph(ProcessState)

# 添加节点（Agent）
workflow.add_node("clean", cleaning_agent.run)
workflow.add_node("evaluate", evaluation_agent.run)
workflow.add_node("extract", extraction_agent.run)
workflow.add_node("report", report_agent.run)

# 定义边（流程）
workflow.add_edge("clean", "evaluate")
workflow.add_edge("evaluate", "extract")
workflow.add_edge("extract", "report")

# 条件分支
def should_manual_review(state):
    if state["evaluation_result"]["confidence"] < 0.7:
        return "manual_review"
    return "extract"

workflow.add_conditional_edges(
    "evaluate",
    should_manual_review,
    {
        "extract": "extract",
        "manual_review": "manual_review_queue"
    }
)

# 编译
app = workflow.compile()
```

## 🎊 总结

### 核心理念

1. **Agent-First** - AI Agent 是核心，不是辅助
2. **Streaming** - 流式输出，提升体验
3. **Observable** - 可观测性，AI 不是黑盒
4. **HITL** - 人类审核，保证质量
5. **Cost-Aware** - 成本意识，Token 就是钱
6. **Secure** - 安全第一，保护隐私
7. **Iterative** - 持续迭代，数据驱动

### 关键区别

**传统 Web 应用开发 vs AI 应用开发**

| 维度 | 传统开发 | AI 应用开发 |
|------|----------|-------------|
| **核心** | 业务逻辑 | AI Agent |
| **确定性** | 确定 | 概率性 |
| **测试** | 单元测试 | Prompt 测试 + 单元测试 |
| **优化** | 代码优化 | Prompt 优化 + 模型选择 |
| **成本** | 服务器成本 | Token 成本 |
| **监控** | 日志 + 指标 | LLM 追踪 + 行为监控 |
| **迭代** | 版本发布 | 持续优化（Prompt/模型） |
