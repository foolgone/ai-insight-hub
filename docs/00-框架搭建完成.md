## 🚀 快速启动

### 后端启动

```bash
cd backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 运行
python app/main.py
```

访问：http://localhost:8000

### 前端启动

```bash
cd frontend

# 安装依赖
npm install

# 运行
npm run dev
```

访问：http://localhost:5173
